# Socratic Deep Questioning

苏格拉底式深度提问法 —— WorkBuddy Skill

面对一个模糊的人生/决策问题，不急着给答案，而是每次只问一个精准问题，逐层深挖，直到收集到足够上下文，再输出一份结构化评估。

## Fields

1. Trigger conditions
2. Input schema
3. Output schema
4. Execution SOP
5. Guardrails
6. Eval examples (anonymized)

## Usage

在 WorkBuddy 中说"用苏格拉底提问法"或"一次只问一个问题"即可触发。
