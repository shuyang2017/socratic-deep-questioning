# Socratic Deep Questioning

苏格拉底式深度提问法 —— 通用决策诊断 Capability Spec Card

面对一个模糊的个人 / 职业 / 情感 / 决策问题，不急着给答案，而是每次只问一个精准问题，逐层深挖关键维度，直到收集到足够上下文，再输出一份结构化评估（判断 / 概率 + 挑战假设 + 可执行方向）。

## 适用场景

- 模糊的人生 / 情感 / 职业 / 决策问题
- 需要判断"可能性 / 可行性 / 根因"，但关键变量都缺失，直接回答会是空谈

## 不应触发的场景

纯知识问答、定义查询、技术 how-to —— 这些直接回答即可，不需要逐层追问。

## 能力规格（6 字段）

1. **Trigger conditions** —— 什么场景 / 话术下启动
2. **Input schema** —— 调用时需要的输入（topic / probe_until / target_output）
3. **Output schema** —— 两阶段产出：追问阶段（多轮单问）+ 综合评估（画像 → 结论 → 挑战假设 → 方向）
4. **Execution SOP** —— 执行流程：领域自适应拆维度、每次只问一个、承接不评判、标记假设、量化定位瓶颈、综合、量化辅助
5. **Guardrails** —— 约束：一次一问、先理解再结论、不评判只挑战事实、结论诚实
6. **Eval examples** —— 脱敏评估样例（标准流程 + 边界反例）

## 核心原则

- 一次只问一个问题，不堆问题
- 在收集够上下文前，禁止"先给答案再补问"
- 维度现场推导、随领域适配，不套固定模板
- 结论诚实，挑战隐含假设，并给可执行方向

## Usage

说"用苏格拉底提问法""一次只问一个问题""问我直到你理解"即可触发。
